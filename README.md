# Car Market Analysis

## Car Market Trends Analysis using Car Dekho Dataset

### Project Overview

This project analyzes used-car data from Car Dekho to identify important market trends and pricing patterns.

The analysis focuses on factors such as manufacturing year, selling price, present price, kilometers driven, fuel type, seller type, transmission, and previous owners.

### Problem Statement

The used-car market contains vehicles with different prices, fuel types, transmission types, and usage levels. It can be difficult to understand which factors have the greatest impact on a car's selling price.

This project uses historical Car Dekho data to identify important trends and pricing patterns that can support better buying, selling, and pricing decisions.

### Objectives

- Analyze the distribution of used-car selling prices.
- Study the relationship between Present Price and Selling Price.
- Analyze average selling price by manufacturing year.
- Compare selling prices across Fuel Type, Seller Type, and Transmission.
- Study the relationship between Kilometers Driven and Selling Price.
- Analyze correlations between important numerical variables.
- Generate visualizations to support data-driven insights.

### Dataset

The dataset contains information about:

- Car Name
- Manufacturing Year
- Selling Price
- Present Price
- Kilometers Driven
- Fuel Type
- Seller Type
- Transmission
- Number of Previous Owners
